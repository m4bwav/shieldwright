# Family

- Parental controls from the platform, not third-party spyware: Google Family Link, Apple Screen Time and Family Sharing, Microsoft Family Safety, console family settings. Age-appropriate, and tell the child what is on.
- Each child gets a standard (non-admin) Windows account; the parent holds the admin account.
- Kids' accounts: parent knows the recovery email and phone; 2FA on with the parent's phone or a passkey; password manager shared via a family vault.
- Teach three rules: nobody legitimate asks for your password or a code sent to you; tell a parent about any message that scares you or asks for pictures or money; do not install what a stranger or a game chat sends.
- Shared devices: screen lock on, automatic updates on, `SW device` on each Windows PC.
- Elderly relatives: same account checklist, plus "call me before paying anyone who contacted you first".
