# Incident playbooks

`SW incident` lists them; `SW incident NAME` prints the ordered steps: token-in-commit, clicked-link, account-taken-over, lost-phone, ransom-note, sextortion-email.

How to run one:
1. Give step 1 at once; a frightened user needs the first action, not the theory.
2. Ask what has already happened and been done; skip finished steps.
3. Steps that change accounts, wipe devices or rewrite history are done by the user; the agent explains where to click.
4. Do changes from a device that is not the suspect one.
5. Finish with prevention: 2FA, password manager, `SW device`, backups.

When to send them to people: money lost (bank first, then police report; US ic3.gov, UK Action Fraud), a child at risk or intimate images (police; US NCMEC Take It Down), a work account (the employer's IT, before anything else).

Token in a commit: see [repo-leak](repo-leak.md) for the full rotate-then-scrub order.
